# tatarhost/skills

A curated, attribution-preserving design and frontend skill library for the tatarhost projects.

**48 skills indexed · 41 mirrored · 7 upstream-only.**

## How the agent should use this repository

Read AGENTS.md first, then select relevant skills from CATALOG.md. Each skill folder has a SOURCE.md with its original repository, source path, branch, and license/terms information. Mirrored skills contain SKILL.md plus their supporting reference files. Read those files before starting the corresponding UI work.

## Layout

- skills/<skill-name>/SKILL.md — original skill instructions (for mirrored entries).
- skills/<skill-name>/references/ or other supporting files — reference material kept beside its skill.
- skills/<skill-name>/SOURCE.md — source and attribution record.
- licenses/ — upstream license texts retained with mirrored content.
- AGENTS.md — mandatory workflow for future design/frontend tasks.
- CATALOG.md — complete 48-item index and mirror status.

## Redistribution status

Some upstream repositories in the requested list did not publish a license. Their entries are indexed as link-only rather than copying their text into this public repository. In particular, the Vercel Agent Skills, Figma MCP Guide, and Remotion Skills sources are linked to their upstream repositories; see each SOURCE.md for the precise note. Figma's README also points to Figma Developer Terms.

The local Impeccable mirror includes its skill instructions and textual references, but not its bundled executable runtime or large generated index files. UI-UX Pro Max data files are included where available as text. The Archify mirror focuses on the skill and its textual reference guides rather than bundling the full viewer/runtime and examples.

## Updating

Check each upstream repository and license before updating. Keep original directory structures and attribution. Do not replace the catalog with an unverified claim of installation: this repository is a readable source library, not an automatic installation into an agent runtime.
